## Обзор

Discord бот предоставляет интерфейс для взаимодействия с LLM (Large Language Model) и включает полнофункциональный музыкальный плеер для воспроизведения треков из YouTube в голосовых каналах.

### Ключевые особенности

- **Музыкальный плеер:** Поиск, очередь, интерактивное управление и прогресс-бар в реальном времени.
- **Интерактивный UI:** Современные компоненты (Select-меню, динамические кнопки) с фиксированной шириной окон.
- **Оптимизация звука:** Нормализация громкости и стабильная скорость воспроизведения без рывков.
- **Гибкий Whitelist:** Двухуровневая система контроля доступа (сервер/канал).

## Архитектура

### Структура пакета

```text
src/bot/discord/
├── bot/                 # Класс бота и обработчики команд
│   ├── client.py        # Инициализация DiscordBot
│   ├── commands.py      # Реализация команд ботa
│   └── constants.py     # Константы (эмодзи, сообщения)
├── player/              # Ядро музыкального плеера
│   ├── player.py        # Основная логика воспроизведения
│   ├── factory.py       # Фабрика для управления плеерами серверов
│   ├── queue_manager.py # Управление очередью треков
│   ├── voice_handler.py # Управление голосовым каналом
│   └── enums.py         # Перечисления состояний плеера
├── views/               # UI-компоненты (Discord Views)
│   ├── base.py          # Базовые классы для UI
│   ├── music_player.py  # Интерактивный пульт управления
│   ├── queue_pagination.py # Пагинация очереди воспроизведения
│   ├── track_selection.py  # Выбор треков из результатов поиска
│   └── constants.py     # Цвета и текстовые блоки UI
├── handlers.py          # Логика чат-интерфейса (LLM)
└── __init__.py          # Точка входа в пакет
```

### Основные компоненты

1. **DiscordBot (`bot/client.py`):** Инициализирует соединение, регистрирует slash-команды и координирует работу других модулей.
2. **MusicPlayer (`player/player.py`):** Отвечает за подключение к голосовым каналам, воспроизведение аудио через FFmpeg и состояние плеера.
3. **QueueManager (`player/queue_manager.py`):** Управляет очередью воспроизведения, режимами зацикливания и навигацией по трекам.
4. **Views (`views/`):** Набор интерактивных компонентов: `MusicPlayerView` (пульт), `TrackSelectionView` (пагинация поиска) и `QueuePaginationView` (пагинация очереди).
5. **MessageHandler (`handlers.py`):** Проверяет права доступа, управляет историей сообщений и взаимодействует с `LLMService`.

## Команды бота

### Музыкальные команды (Slash Commands)

| Команда | Описание |
| :--- | :--- |
| `/search <запрос>` | **Живой поиск** с автодополнением. Первый подходящий трек из списка добавляется мгновенно. |
| `/play <запрос>` | **Расширенный поиск** с выбором. Показывает список треков (до 50) с выбором через меню. |
| `/link <ссылка>` | Воспроизведение музыки по прямой YouTube/VK ссылке. |
| `/playlist <ссылка>` | Загрузка всех треков из YouTube плейлиста. |
| `/skip` | Переход к следующему треку. |
| `/previous` | Возврат к предыдущему треку. |
| `/pause` | Приостановка воспроизведения. |
| `/resume` | Возобновление воспроизведения. |
| `/stop` | Полная остановка плеера и выход из канала. |
| `/queue` | Просмотр текущей очереди треков. |
| `/nowplaying` | Вызов интерактивного пульта управления. |
| `/help` | Показать подробную справку (включая описание кнопок пульта). |

> [!TIP]
> Команды перемешивания (`shuffle`) и получения текста песен (`lyrics`) доступны через кнопки на интерактивном пульте управления.

## Музыкальный плеер

### Интерактивный пульт (`MusicPlayerView`)

При запуске музыки или вызове `/nowplaying` появляется сообщение с расширенным 3-рядным пультом управления. Все кнопки используют кастомные иконки, управляемые через `EmojiManager`.

#### Ряд 1: Навигация и контроль времени
- **⏮️ (Previous)** — Перейти к предыдущему треку.
- **⏪ (Rewind)** — Перемотка на 10 секунд назад.
- **⏯️ (Play/Pause)** — Пауза или возобновление.
- **⏩ (Forward)** — Перемотка на 10 секунд вперед.
- **⏭️ (Next)** — Перейти к следующему треку.

#### Ряд 2: Очередь и дополнительные функции
- **🔀 (Shuffle)** — Перемешать текущую очередь.
- **🔁 (Loop)** — Циклическое переключение режимов: Без повтора → Повтор трека → Повтор очереди.
- **📋 (Queue)** — Показать текущую очередь (эфемеральное сообщение).
- **📑 (Lyrics)** — Получить текст текущей песни (использует `LyricsService`).
- **⏹️ (Stop Only)** — Остановить воспроизведение без выхода из канала.

#### Ряд 3: Громкость и системные команды
- **🔇/🔊 (Mute)** — Включить/выключить звук.
- **🔉 (Vol Down)** — Уменьшить громкость на 20%.
- **🔊 (Vol Up)** — Увеличить громкость на 20%.
- **➕ (Add Query)** — Открыть модальное окно для быстрого поиска и добавления трека.
- **❌ (Disconnect)** — Полная остановка и выход из голосового канала.

**Прогресс-бар:** Обновляется автоматически каждую секунду, показывая текущую позицию и лимиты громкости.

### Пагинация и интерфейс

Для поддержания чистоты чата и удобства управления используется современная система интерфейсов:

- **Консолидация сообщений:** Бот не плодит новые сообщения при поиске или загрузке. Сервисные уведомления («Поиск...», «Загрузка...») редактируются в финальный результат или автоматически удаляются через 10 секунд.
- **Select-меню в поиске:** Выбор треков в `/play` осуществляется через выпадающий список. Это позволяет видеть названия треков и авторов прямо в меню выбора.
- **Живой поиск (/search):** Использует механизм автодополнения Discord для мгновенного поиска. Вы можете начать вводить название, и бот предложит 10 наиболее релевантных вариантов. Это самый быстрый способ включить музыку.
- **Фиксированная ширина окон:** Все окна (плеер, поиск, очередь) имеют унифицированную ширину, настраиваемую через константу `UI_WIDTH`.
- **Пагинация в поиске и очереди:** Результаты поиска в `/play` и список очереди разбиты на страницы (по умолчанию 10 элементов на страницу).

### Плейлисты YouTube

Команда `/playlist` позволяет быстро добавить сотни треков:

- **Быстрый парсинг:** Бот извлекает метаданные всех видео в плейлисте без их предварительной загрузки, что обеспечивает почти мгновенное добавление.
- **Автоматическое начало:** Если плеер был остановлен, воспроизведение начнется автоматически с первого трека плейлиста.
- **Комбинирование:** Вы можете добавлять несколько плейлистов или отдельные треки по ссылкам — они просто встанут в конец текущей очереди.

### Особенности работы

- **Авто-отключение:** Бот автоматически покидает канал через 10 минут бездействия (пустая очередь или пауза).
- **Нормализация звука:** Используется фильтр `loudnorm` и фиксированная частота 48кГц для выравнивания громкости разных треков.
- **Стабильная скорость:** Флаг `-re` в FFmpeg устраняет эффекты ускорения или замедления звука («эффект бурундука») в начале воспроизведения.
- **Авто-очистка очереди:** Если воспроизведение завершено, очередь автоматически очищается через 30 минут бездействия.
- **Очистка при отключении:** При ручном или принудительному выходе бота из канала (в том числе при удалении его из войса) состояние плеера и UI сбрасываются немедленно.
- **Автоудаление уведомлений:** Все технические сообщения («Трек добавлен», «Ошибка загрузки») удаляются сами через 10 секунд.
- **Поиск:** По умолчанию `/play` ищет до 50 результатов (настраивается через `MAX_SEARCH_RESULTS`).
- **Тайм-ауты:** 
  - Поиск в `/play` и `/link` ограничен 30 секундами (защита от зависаний API).
  - Автодополнение в `/search` ограничено 2 секундами (требование Discord для отзывчивости интерфейса).
- **Отображение циклов:** Режим зацикливания («Loop») всегда отображается на отдельной строке в плеере для лучшей видимости текущего состояния.

## Система Whitelist

Контроль доступа в Discord работает на двух уровнях:

1. **Сервер (Guild):** Если сервер добавлен в whitelist, бот может работать во всех его каналах по умолчанию.
2. **Канал:** Можно точечно включать или отключать бота в конкретных каналах.

### Логика проверки

- Если бот в ЛС (DM): Проверяется настройка `discord_allow_dms`.
- Если на сервере:
  1. Проверяется, активен ли конкретный канал в базе.
  2. Если канала нет, проверяется активность сервера.
  3. Если обоих нет, бот реагирует только если включена настройка `discord_allow_new_chats`.

## Интеграция с LLM

### Принципы работы

- **Упоминания:** В каналах бот отвечает только если его упомянули (`@Бот`).
- **Контекст:** Бот помнит последние `N` сообщений (настраивается через `discord_memory_limit`).
- **Никнеймы:** При генерации ответа LLM видит никнеймы пользователей для более персонализированного общения.
- **Длинные сообщения:** Если ответ LLM превышает 2000 символов, бот автоматически разбивает его на несколько частей.

## Настройки

Управление основными параметрами осуществляется через веб-панель администратора.

| Ключ | По умолчанию | Описание |
| :--- | :--- | :--- |
| `discord_bot_enabled` | `false` | Глобальный переключатель Discord бота. |
| `discord_allow_new_chats` | `false` | Автоматически добавлять новые серверы в whitelist. |
| `discord_allow_dms` | `true` | Разрешить общение в личных сообщениях. |
| `discord_memory_limit` | `10` | Количество последних сообщений, доступных LLM. |
| `discord_music_enabled` | `true` | Включить/выключить музыкальный плеер. |
| `discord_seek_time` | `10` | Время перемотки трека в секундах. |
| `discord_respond_everyone` | `false` | Отвечать на все сообщения или только на упоминания. |
| `ENABLE_DISCORD` | `true` | (`.env`) Включить/выключить инициализацию бота при старте приложения. |

### Технические настройки (код)

Для тонкой настройки интерфейса и производительности используйте следующие файлы:

#### 1. `src/bot/discord/views/constants.py` (UI и Лимиты)

- `MAX_SEARCH_RESULTS`: Количество треков, выдаваемых за один поиск (по умолчанию 50).
- `UI_WIDTH`: Ширина всех Embed-окон бота.
- `DEFAULT_ITEMS_PER_PAGE`: Количество элементов на одной странице пагинации (обычно 10).
- `DEFAULT_VIEW_TIMEOUT`: Время жизни кнопок и меню до их отключения (сек).

#### 2. `src/services/music_service.py` (Аудио и Поток)

- `FFMPEG_OPTIONS`: Параметры обработки звука (битрейт, нормализация, переподключение). Ключ `-re` регулирует стабильность скорости, а `-af loudnorm` — громкость.

#### 3. `src/bot/discord/bot/constants.py` (Инфраструктура)

- `DEFAULT_PREFIX`: Префикс для команд (актуально для текстовых команд, не для Slash).
- `OPUS_PATH`: Путь к библиотеке `libopus` (критично для Docker/Linux).

## Требования и установка

### Системные зависимости

Для работы голоса и музыки внутри Docker или на сервере должны быть установлены:

- `FFmpeg` (обработка аудио).
- `libopus` (кодек для Discord).
- `libsodium` (шифрование).

Эти зависимости включены в стандартный `Dockerfile` проекта.

### Запуск вручную (вне Docker)

```bash
# Установка Python-зависимостей
pip install discord.py yt-dlp PyNaCl

# Установка FFmpeg (Ubuntu/Debian)
sudo apt update && sudo apt install ffmpeg
```
